# xFalcon Desktop v0.5.15

Changes since v0.5.14:

- Paste images, CSV, Excel and supported files into chat on Windows and macOS, with file validation and a 10 MiB per-file limit.
- Redesigned Reports with actual report previews, four-column layouts, search, sorting, pin filters and subtle hover effects.
- Added demo-only report actions for refresh, calendar/cron scheduling, email sharing and PDF/HTML/PNG export. Backend integration is not included.
- Refined Datasets and reduced layout gaps while retaining rounded panels.
- Simplified Settings, removed duplicate controls and added support@xfalcon.ai.
- Moved routine conversation sync into the background while preserving offline warnings and recovery behavior.
