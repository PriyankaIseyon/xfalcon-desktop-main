# xFalcon Desktop v0.5.16

Changes since v0.5.15:

- MCP server OAuth client details are saved on your device when you save the server, so a cancelled, timed-out or refused browser sign-in no longer discards them.
- Edit MCP server now shows the client ID already saved for a server instead of an empty field, states when a client secret is saved, and removes the saved client when the ID is cleared.
- Signing out of an MCP server keeps its client details, so signing back in takes one click.
- Sign-in now finds a server's OAuth description when it is published outside the standard location, so more third-party MCP servers can be added without configuration.
- macOS installers can now carry the workspace MCP sign-in client, matching Windows.
- Added the count of servers with saved client details to the diagnostics report.
