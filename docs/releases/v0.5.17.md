# xFalcon Desktop v0.5.17

Changes since v0.5.16:

- Adding an MCP server is now a shorter form: every server this app connects to signs in through the browser, so there is no authentication method to choose and no header or token to paste.
- The Client secret field now shows that a secret is already saved on this device instead of appearing empty, so an edit no longer looks like the saved value was lost.
- Name, Server address, Client ID and Client secret are marked as required, and a server cannot be saved until each is supplied. A secret already saved on this device still counts as supplied.
- New servers default to the Allow approval mode, so read-only tools run without a prompt.
- Removed Test connection from the server form. It could only test a server that was already saved and signed in, and browser sign-in already reports whether the server answered.
- Settings now shows the application version again instead of "Unknown".
