# xFalcon Desktop v0.5.18

Changes since v0.5.17:

- Sending a message no longer waits on a request for the tenant's model list. The list is read once when the workspace loads and reused, so the first words of an answer arrive sooner.
- Switching between conversations is faster for the same reason. The model list behind the composer is no longer re-requested on every switch.
- A brief tenant outage no longer blocks a send that would otherwise work, because the send no longer depends on that request. Sending still needs the tenant to be reachable for the conversation itself.
- The model list is refreshed when the app starts, and when a Settings change reloads the workspace. A model an administrator enables or disables while the app is open is picked up the next time the app starts.
