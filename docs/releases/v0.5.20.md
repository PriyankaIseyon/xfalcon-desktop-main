# xFalcon Desktop v0.5.20

Changes since v0.5.19:

- Two new chat models are available:
  - **Luna** now always uses the latest GPT Luna model, currently GPT-6 Luna.
    It used to be fixed to GPT-5.6 Luna.
  - **Sol** is new, and always uses the latest GPT Sol model, currently
    GPT-6 Sol.
- Conversations that already used the earlier Luna keep running on it.
- If Luna was your default model, it stays your default and moves to the new
  Luna.
- The app now signs in only to the workspace it was built for. Changing its
  configuration files or environment settings can no longer point it at
  another sign-in service.
- Projects, saved reports, and conversation search now require an active
  session. If your session ends, for example because your account was signed
  out elsewhere, they stop until you sign in again. Working offline with a
  session that can still renew is unaffected.
- The sign-in screen now explains that sign-in completes in your browser and
  then returns you to the app.

Known limits:

- Luna and Sol appear only when your workspace offers them. If they are
  missing, your workspace administrator needs to enable them.
