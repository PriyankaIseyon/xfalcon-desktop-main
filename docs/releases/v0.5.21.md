# xFalcon Desktop v0.5.21

Changes since v0.5.20:

- You can now import `.skill` files. A `.skill` file is a packaged skill, for
  example one made with Claude's skill-creator. Importing one used to fail
  with "frontmatter delimiters not found".
- Skills keep the files they bundle, such as references, scripts, and assets.
  The agent reads a bundled file when the skill's instructions point to it.
  Nothing in a skill is ever run.
- Skill folders and ZIP archives also keep their bundled files. A ZIP of
  several `.skill` files imports every skill in it.
- Settings shows how many files each skill bundles.
- Each account now has its own skills. Another person who signs in on the
  same device no longer sees or uses your skills. Skills you imported before
  this update move into the first account that signs in.
- You can ask the agent which skills and tools you have. It lists them by
  name and description, and uses each tool's real name from its server.
- Importing no longer freezes the window, and more published skills import.
  This includes skills that declare their allowed tools as a single line, and
  files saved with a Windows byte-order mark.

Known limits:

- A skill can bundle at most 512 files and 32 MB. A larger skill is refused
  with a reason instead of being imported without some of its files.
- A library holds at most 256 skills per account.
- The agent can read bundled text files, but not images or other binary
  files.
