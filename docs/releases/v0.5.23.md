# xFalcon Desktop v0.5.23

Changes since v0.5.22:

Provider keys

- Settings → Model providers has a Remove button on each key. Removing asks
  first, and says plainly that the key goes for every signed-in xFalcon app,
  not only this computer.
- Chat turns off by itself when you remove the last key it could use.

File history

- Each revision in History & Revisions has "Show changes". The diff loads
  only when you click it, side by side: the revision on the left, the file as
  it is now on the right. You can switch to a single column.
- "This change only" compares a revision with the next one, so you see just
  the edit that replaced it, not everything since.
- Diffs are shown for files up to 1 MB and edits up to 2,000 changed lines.
  Past that, the panel says the diff is too large to show. Restoring still
  works.
- Sensitive files such as `.env` are never read to make a diff.
- History keeps up to 50 revisions per file, and up to 512 MB of revisions per
  account. The oldest go first.

Look and feel

- Menus, dropdowns, right-click menus, tooltips, the command palette, the
  composer's `/` and `@` lists, and every dialog now open and close with a
  short, smooth animation. Menus grow from where you clicked. Anything you
  close fades out, and the app behind it is ready at once.
- Notifications use the same motion. When one closes, the others glide into
  place instead of jumping.
- With reduced motion turned on in your system settings, nothing animates.

Known limits

- A diff compares whole lines. A change inside a very long line shows as the
  whole line removed and added.
- Revisions of files over 64 MB are not kept, as before.
