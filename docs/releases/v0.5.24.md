# xFalcon Desktop v0.5.24

Changes since v0.5.23:

Attachments in chat

- The model now reads the files you attach. Ask about a CSV, a spreadsheet, a
  text or code file, or an image, and the answer uses it. Earlier files in the
  same chat stay readable in follow-up questions.
- Large files are read as far as fits, and the model is told how much it saw.
  A file that cannot be read is named as unreadable instead of being skipped.
- Attach no longer opens a new chat. On the new-chat screen, the file picker
  opens first and you stay where you are; the chat starts when you send.
  Cancelling the picker leaves nothing behind.
- A chat started with an attachment gets a real title from your message, or
  from the file names when you send files alone, instead of "New Chat".

Search

- Search has one place: the Search button at the top right, or Ctrl/Cmd+K.
  The search box in the sidebar is gone.
- Moving through results with the arrow keys keeps the selected result in view.

Fixes

- Removing a provider key that another app already removed now just succeeds,
  and a removal whose answer was lost reloads the key list.
- The removal warning only says chat stops when it is your last working key for
  that provider.
- Closing a menu inside a dialog no longer breaks Tab navigation in the dialog.
- A notification that returns to the stack no longer shows twice.

Known limits

- Images are read by models that accept images. Workbooks are read as text,
  sheet by sheet; charts and formatting inside them are not.
- A chat reserved for files and then left open when the app quits stays as an
  empty chat until deleted.
