# xFalcon Desktop v0.5.26

Changes since v0.5.25:

Private models

- Add, edit, and remove private OpenAI-compatible models in Settings. Their API
  keys stay hidden after saving.
- Use a private model for chat through its own endpoint and key. The app checks
  HTTPS addresses and supports tools and images when the model allows them.
- Choose one default model across private models and OpenRouter. New chats use
  that model; existing chats keep their selected model and key route.

Settings

- Models and connections now share one section. The default model has a compact,
  scrollable dropdown with provider labels, even when many models are available.
- Provider keys are labeled separately from the default model choice.
