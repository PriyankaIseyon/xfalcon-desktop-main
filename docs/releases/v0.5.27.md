# xFalcon Desktop v0.5.27

Changes since v0.5.26:

Agent

- Updating several project files in one request now completes reliably. File
  edits tolerate small whitespace differences, report the closest matching line
  when an edit does not apply, and refuse unsafe whole-file replacements.
- Long conversations are now compacted automatically for every model, not only
  Claude, so large projects no longer stop at the context limit.
- The project prompt is tuned for current Claude, GPT-6 (Luna and Sol) and Grok
  models.

Reliability

- Fixed a failure where a denied or failed tool call ended the run and left the
  chat unusable. A chat left in that state now recovers on the next message.
- A run that stops making progress for five minutes, or exceeds its time limit,
  is stopped and you are asked to retry. Runs that fail before starting now show
  a message instead of an endless "thinking" indicator.
- Saving a file from the viewer, restoring a revision, and saving a report are
  no longer refused for lines that resemble placeholders.
