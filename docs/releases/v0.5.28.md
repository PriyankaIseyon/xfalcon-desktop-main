# xFalcon Desktop v0.5.28

Changes since v0.5.27:

Chat

- Files attached to a message now stay available to the model through the whole
  run, including after it uses tools. Fixes the model reporting that it could
  not see an attachment.
- Attached files now appear under your message in the conversation.
- Row counts for attached CSV, TSV and Excel files now report the whole file
  instead of the portion that was read.
- The text you are typing no longer carries over when you switch chats.
- The "thinking" indicator is redesigned: a compact animated loader with a short
  status word and an elapsed timer. It starts collapsed.
- Fixed a skill-loading step that could appear as failed even though it worked.

Projects

- The file tree now draws branch lines from each folder to its files and
  highlights the path to the selected file. File type tags are aligned.
