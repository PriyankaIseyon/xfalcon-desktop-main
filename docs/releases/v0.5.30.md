# xFalcon Desktop v0.5.30

Changes since v0.5.29:

Chat

- Streamed answers stay responsive while conversation history is being saved.
  Slow saves apply bounded backpressure without blocking the chat view.
- Switching between active chats preserves streamed text, thinking, tool activity,
  and event ordering. Late events cannot revive a finished run.
- Answer text reveals at a steady pace and catches up quickly after large bursts.
  Completion, reduced motion, and background views show the full available text
  immediately. The typing caret has a softer pulse and follows wrapped text.
- The company Qwen model receives instructions to keep planning and tool narration
  in its reasoning channel. Answers still stream immediately. This relies on the
  model following the instruction; unlabelled narration cannot be guaranteed hidden.
- Hovering or focusing the composer model name explains that models change in
  Settings and an existing chat keeps its original model.

MCP tools

- A delayed authorization refusal from an old connection remains retryable after
  a replacement connects. It cannot erase renewed credentials or ask for stale
  reauthorization.
- Slow tool discovery no longer holds up session invalidation. Reconnected servers
  still refresh and validate their own tool schemas.
- Tool timeouts cancel their own execution and perform bounded cleanup without
  cancelling unrelated calls.

Release maintenance

- Successful staging delivery keeps five rolling GitHub releases, including drafts,
  and deletes older release entries and their attached assets. The current published
  latest release, if present, is protected within those five slots. Failed builds
  or delivery do not run cleanup. Git tags and S3 delivery files are preserved.
