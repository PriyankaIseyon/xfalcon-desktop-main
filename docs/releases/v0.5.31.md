# xFalcon Desktop v0.5.31

Changes since v0.5.30:

Chat and navigation

- Chat history avoids repeated size calculations while responses stream.
- Automatic chat naming accepts concise title text from Luna, Sol, and Sonnet.
  A manual rename keeps priority over a late automatic title.
- Sidebar chat names use the available width and reveal the full name when
  clipped. Pin and Delete appear on hover and keyboard focus, with enough space
  for both controls in regular chats and project chats.
- Project chat titles and project names stay inside the header, including while
  renaming. Project file highlights leave curved tree connectors visible.

Project tools and context

- Local file changes finish with a recorded outcome when Stop or a deadline
  arrives. Cancelled queued changes cannot start writing later.
- File edits check the expected content before replacing it. File and directory
  moves check their destination, and failed staged writes clean up their files.
- Bounded reads reject incomplete content hashes and binary content in skipped
  lines. File and skill paging instructions keep larger workflows explicit.
- Compaction requires a complete summary, preserves unsummarized continuation
  text, and keeps Sonnet signed thinking with the matching message prefix.
- Skill pages survive ordinary context pruning. Available and explicitly named
  skills receive clear loading and follow-up paging instructions.

Settings and delivery

- Remove actions use consistent labels, styling, confirmations, and focus return.
- Successful staging delivery keeps five rolling GitHub releases and their
  attached assets. Git tags and staging delivery files remain available.
