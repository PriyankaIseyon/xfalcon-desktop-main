# xFalcon Desktop v0.5.33

Changes since v0.5.32:

- Private models now discover available models from your endpoint. If the
  endpoint has no model list, enter the exact model ID, including any prefix.
- Review model limits and capabilities before saving. Settings returned by the
  endpoint are labeled. Missing settings use clearly labeled suggestions that
  you can update for your model. Temperature and Top P are saved on this device.
- A short greeting checks the connection before a new or changed connection is
  saved. Errors stay in the dialog for correction. Duplicate models are blocked
  by endpoint, API key, and exact model ID, even with a different display name.
  Models with missing output limits stay visible for repair or removal.
- Parallel file reads and edits share safe local-store initialization. Completed
  tool results update run progress. A started file update finishes before its run
  can be stopped, so the recorded outcome matches the completed work.
- Provider streams accept valid optional empty and null fields. Malformed tool
  batches fail before any calls execute, and oversized output stops before it
  reaches the chat or saved history.
- Project CSV and TSV files can chart numeric values or category counts. Large
  files can chart the current page. Charts over 5,000 plotted values are withheld
  with a clear message. File and chart controls fit at each reading size.
