# xFalcon Desktop v0.5.34

Changes since v0.5.33:

- Haiku joins the model list and is the default for a new chat. A model you chose
  before still wins, and older conversations keep their model. Haiku appears once
  your xFalcon workspace serves it.
- Reports now live in xFalcon, so they open on any device you sign in to. Ask the
  assistant to build a dashboard and it saves it and refreshes it with current data.
  It opens from the Reports page. The old reports kept only on this device are no
  longer read.
- The assistant now says "xFalcon" and keeps report ids and tool names out of its
  replies.
- The Reports page lists every kind of report, including Excel workbooks and
  PowerPoint decks. You can share a report with your organization or make it private
  again, hide a report from your own list and bring it back, and filter by All, Mine,
  Shared with me and Pinned.
- A report made in a project chat is linked to that project on this device. A new
  Project filter shows one project's reports, or the reports made outside any
  project. Reports saved before this update, or on another device, appear under
  "No project".
- A report says when its data was stored, one line at a time, and never claims the
  data is current. Refresh shows what each dataset did, opens the details by itself
  if one failed, and keeps the report on screen until the new page has loaded.
- Export writes a real file where you choose: a dashboard as one HTML page, a
  workbook or deck as the file xFalcon built. A download that is cut short or is not
  a real workbook never replaces your existing file. Save to project copies a
  dashboard's page into a project folder.
- Buttons keep their text readable when you hover or press them, and a selected
  filter keeps its fill under the pointer. The filter row is a single control, and
  the hidden-reports toggle is a switch beside it.

Upgrade note: this version adds a table to the local project database. A device that
opens it keeps working on the next version, but cannot go back to an older build
without clearing project trust.
