# xFalcon Desktop v0.5.35

Changes since v0.5.34:

- Report cards show the preview image xFalcon stores for each report, the same one
  xFalcon on the web shows. A preview loads once and stays: scrolling, searching or
  switching layout no longer reloads it.
- On a dashboard you own, a new button creates or updates its preview. Opening a
  dashboard of yours that has no preview makes one in the background, and Mine offers
  to create every missing preview in one go, with a Stop button.
- Cards and rows name the database or schema a report reads, and its project when it
  has one.
- The report table, in List view and under Older reports, shows a small preview, the
  owner, pages, who can see the report, and when it was created and updated. Sort by
  Name, Owner, Created or Updated from the column headers. Click anywhere on a row to
  open the report. The table fits the window and scrolls sideways only when the
  window is very narrow.
- Report actions are always visible, not only on hover. On a report someone else owns
  you see only Pin and Hide: Rename, Delete and Share are left out.
- Error messages close on their own after 15 seconds. Hovering over them or focusing
  them keeps them open.
- Tools that an xFalcon server meant only for its own screens are no longer offered
  to the assistant.
