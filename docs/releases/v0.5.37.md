# xFalcon Desktop v0.5.37

Changes since v0.5.36:

- Numbers in tables are read correctly whatever the format. `-$1,200`, `+$5`, `1,5`,
  `1.234,56`, `1 234,5` and `5,00 €` now read as the number they show, on every
  machine. Before, a negative amount was drawn as a gap in a chart and sorted as text,
  and a European number could be read a hundred or a thousand times off.
- A column that cannot be read as numbers with confidence is left as text and is not
  offered as a chart measure, rather than being charted wrongly.
- Charts place points on a time axis. Uneven dates are spaced by their real distance,
  not evenly by position, and the axis labels are calendar boundaries.
- Chart axes use round tick values (1, 2, 5 and their multiples) and start at zero for
  bars and areas. Axis labels, tooltips and pie shares show numbers the same way, in your
  system's number format.
- File sizes use the same number format.
- CSV export is unchanged: each cell is written as it arrived.
- Internal: the skill file parser no longer depends on an unmaintained library, which
  clears the dependency policy check. Documentation was brought back in line with the code.
