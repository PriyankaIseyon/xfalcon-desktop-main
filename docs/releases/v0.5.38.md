# xFalcon Desktop v0.5.38

Changes since v0.5.37:

- **Settings is four sections, each one box.** Appearance, Models & connections, Agent
  capabilities and Application. Model reasoning and Try next suggestions moved to Agent
  capabilities, next to Skills. Support and Data & reset moved into Application.
- **Models & connections is one box.** Default model, private models, model providers
  and MCP servers sit inside it, separated by lines instead of separate cards. Provider
  keys are a list with an Add button that is always there. MCP servers show one status
  and a one-line summary, with Edit and Remove as icon buttons.
- **Signed out after 12 hours without input.** A running agent run is never cut short,
  and an open dialog holds the sign-out for at most a day. The sign-in screen says why
  you were signed out.
- **Report a security issue** (Settings → Application → Support) opens your mail app with
  an urgent, prefilled message to support@xfalcon.ai. Nothing sensitive is filled in.
- **Reset xFalcon replaces Clear local data.** It erases everything the app stored on
  the device, closes, and reopens as a fresh install. The Windows uninstaller erases the
  same data, except during an update or an upgrade install.
- **Private and on-prem deployments.** MCP servers on localhost or a private address,
  and plain-http object storage, work in release builds. The stricter rules are kept in
  the code behind two switches that are off.
- **Sign-in and session fixes.** A token refresh that finishes after sign-out no longer
  signs you back in, and a sign-in you cancel no longer completes.
- **Local security log.** A tamper-evident record of security-relevant actions, included
  in Settings → Application → Support → Export diagnostics report. It holds names and
  outcomes only, never contents.
- **Logs are redacted as they are written,** and existing logs are cleaned at start-up:
  keys, tokens, passwords, e-mail addresses, phone numbers and URL credentials.
- **Files you choose are handed to the app by id,** not by path. Choosing more than 4,096
  skill files now says so.
- **macOS releases must be signed.** The release build fails if the signing secrets are
  missing.
- Internal: audit, purge and redaction hardening from two review rounds; documentation
  brought back in line with the code.
