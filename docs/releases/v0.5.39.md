# xFalcon Desktop v0.5.39

Changes since v0.5.38:

- **Settings buttons line up.** Labelled buttons in Settings come in two widths, so the
  buttons down the right edge of each box share an edge. Labels do not wrap on wide
  windows and may wrap on narrow ones.
- **Edit and Remove look the same everywhere.** MCP servers now use the same labelled
  Edit and Remove buttons as private models, provider keys and skills, instead of icon
  buttons. Refresh is a bordered button like its neighbour.
