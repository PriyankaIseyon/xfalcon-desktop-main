# xFalcon Desktop v0.5.40

Changes since v0.5.39:

- **Updates go straight to the latest version.** The app no longer installs an older
  release first and a newer one after it. Every check reads the current release, a newer
  release replaces one that is already downloaded, and Restart to update checks once more
  before it installs.
- **Answers type out smoothly.** A streamed answer is revealed at a steady pace, for
  every model, instead of arriving in blocks. When the model finishes, the rest is shown
  quickly instead of all at once.
- **A finished answer is not drawn twice.** The answer stays on screen exactly as it was
  streamed when the response completes, so it no longer looks as if it was generated a
  second time.
- **Reset xFalcon.** The button in Settings is labelled "Reset xFalcon", without the
  trailing dots.
- **Security.** The build tooling dependency `source-map-js` is updated to 1.2.2, which
  fixes GHSA-68fv-2mgg-jv7q. It is used only to build the app and is not part of the
  shipped app.
