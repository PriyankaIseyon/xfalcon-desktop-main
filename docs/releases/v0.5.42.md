# xFalcon Desktop v0.5.42

Changes since v0.5.41:

- **Formatted release notes.** Settings now displays update notes with proper headings, lists, links, tables and code formatting.
- **Stronger prompt-injection defenses.** Hardened how the assistant handles instructions embedded in files, tool results, skills and project metadata, including during conversation summaries and follow-ups.
- **More useful assistant guidance.** Improved guidance for reusing verified results, calculating from available data and stating assumptions. Available tools, connected servers and skills remain discoverable with brief descriptions.
- **Better privacy in logs and diagnostics.** Improved redaction of credentials and personal information, including malformed service responses and large log entries.
- **Automatic background cleanup.** Unused temporary upload files are checked every 30 minutes without blocking your work. Cleanup starts after the first 30 minutes, skips files needed for active work or retries, and retries removal failures later.
- **More reliable upload cancellation.** Fixed cases where a cancelled upload could start later. Improved coordination between uploads, retries and temporary-file cleanup.
- **Safer local data removal.** Strengthened file ownership checks and improved reporting when local data cannot be fully removed.
- **Safer skill updates.** Failed skill replacements retain recovery copies, while obsolete import files can be cleaned up.
- **Security documentation and verification.** Updated security, data-lifecycle and assurance documentation, and added repeatable scanning of application prompts.

**Release review note:** Four deferred `rustls` advisories still fail the dependency gate. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
