# xFalcon Desktop v0.5.43

Changes since v0.5.42:

## A new look and a reworked shell

- **Shared xFalcon design language.** The light theme now uses the colours of the shared xFalcon design system, so the desktop app, the web app and xfalcon.ai read as one product. The accent is a deep teal with white text on it, in place of bright cyan. Muted text, borders, surfaces, status colours and the code highlight use the shared set. The grey surfaces of the dark theme are unchanged.
- **Easier to read.** Faint text on the sidebar now meets the 4.5:1 contrast minimum (it was 4.35:1), and the accent reads as both text and fill colour (5.5:1 with white text on it).
- **Charts use a fixed colour order.** Series one to six keep their order, with a colour set checked for light, dark and high contrast. A seventh series and beyond share one overflow grey instead of repeating the first colour.
- **Two text sizes on the chat screen.** The sidebar, title row, composer meta line and suggestion cards read at one size: 12 px at the default reading size, 14 px at medium and 16 px at large. The conversation and the message box read one step larger. Sidebar group labels such as "This week" are now sentence case in muted ink, in place of small capitals.
- **Two surfaces, like a chat app.** The navigation and the workspace are divided by one line, with no gaps or rounded pane corners between them. The title bar is the top row of the workspace, with no border of its own. The side panel keeps a hairline under its header.
- **One falcon.** The mark has no tile, border or shadow, is drawn larger, and uses one colour everywhere: the sidebar, the sign-in and start-up screens, the account avatar and the empty chat. The wordmark shows "xFalcon" with the x in the accent colour.
- **A "+" on Chats, Projects and Datasets.** Each starts a new chat, opens the new-project sheet or opens the dataset file picker, from any page. It shows when you hover the row or focus it with the keyboard, and always on a touch screen.
- **A resizable sidebar.** Drag the sidebar's right edge, or focus it and use the Left and Right arrow keys (Shift for bigger steps). Home and End jump to the narrowest and widest size, and Enter or a double-click resets it. The width holds while the app is open, including after you collapse and reopen the sidebar, and returns to the default on the next launch.
- **macOS: window buttons in the app's own header.** The native title bar no longer repeats "xFalcon" above the sidebar. The close, minimise and zoom buttons sit in the app's top row, the brand sits on the row below, and you can still drag the window by that row and double-click it to zoom. The collapsed sidebar rail keeps the buttons on the same top band. Menus, tooltips and the command palette are solid on macOS, so text behind them no longer shows through. Windows and Linux keep their native title bar.
- **Smoother selectors.** Tabs and segmented controls now slide a selection highlight between choices, and you can drag it from one choice to another. It respects the reduced-motion setting.

## Slow models, slow tools and rate limits

- **A slow model is reported as slow.** When a model sends nothing for too long, the message now says the model took too long and suggests trying again or choosing a faster one. It no longer says the provider is unavailable or tells you to check a private model's host. "Could not be reached" now means only that the host did not answer the connection.
- **Private models get more time.** A private model can stay silent for up to 240 seconds, up from 90 seconds, while a self-hosted server reads a long prompt. This is still under the five-minute run stall limit.
- **Long answers are no longer cut at ten minutes.** A single streamed answer can now run as long as the run itself, up to one hour.
- **Slow warehouse queries finish.** A tool call to a server that sends keep-alive pings, as Data Analyst does, can now run for its full two-minute budget. A request used to end at 45 seconds as "transport disconnected", and the assistant then ran the same query again into the same limit.
- **A Data Analyst rate limit is treated as a rate limit.** The Data Analyst server limits tool requests for each signed-in user (200 a minute by default). When the server asks the app to wait 30 seconds or less, the app waits once inside the call and tries again, and keeps the connection open. A limit that lasts longer reaches the assistant with the wait to observe, so it stops retrying straight into it. A rate limit on the exact-result path is no longer reported as a timeout.
- **Clearer tool failures.** A tool that timed out tells the assistant not to repeat the same call and to narrow it (fewer rows, a shorter date range, fewer columns) or to tell you. A dropped connection says it is reopened on the next call.

## Projects, Reports and Settings

- **Schemas follow the selected file.** In a project, the Schemas tab shows the schema of the file you have open. It says so when that file has no CSV, JSON or SQLite schema, and it still shows every schema when no file is open.
- **Updates.** "xFalcon is up to date." appears as a centred badge in the software-update row, in place of a full-width banner, and clears after five seconds.
- **Reports filters** use the same selector as the other controls.

## Security and maintenance

- **Dependency security update.** `rustls` is updated from 0.23.45 to 0.23.46, which fixes RUSTSEC-2026-0346, RUSTSEC-2026-0347, RUSTSEC-2026-0348 and RUSTSEC-2026-0349. The dependency policy check (`cargo deny check`) passes on this source.
- **Window permissions.** The window is granted two more Tauri permissions, `core:window:allow-start-dragging` and `core:window:allow-internal-toggle-maximize`, so the header and the sidebar brand can drag and zoom the window. These regions are present on every platform, not only macOS. The capability tests were updated to match.
- **Documentation.** Security, release and runtime documentation were reconciled with the v0.5.42 source and updated for these changes. A draft proposal for a tenant catalogue of MCP servers and per-project tool scope was added under `openspec/changes/`. It lists five Data Analyst facts to check before any code is written, and it changes no behaviour.

**Release review note:** The release job compiles and lints the macOS window-button placement on macOS. This repository holds no record of its on-screen result on a Mac. The dark theme's grey surfaces were not migrated to the new design language, so the light and dark themes now differ. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
