# xFalcon Desktop v0.5.44

Changes since v0.5.43:

## Claude and ChatGPT plans as optional providers

- **Two plan providers, off by default.** Next to OpenRouter, Settings can use a Claude subscription or a ChatGPT plan as a model source. Both stay off until you turn them on. Existing providers are not affected.
- **Claude subscription.** xFalcon runs the `claude` command already installed on your computer, once for each message. xFalcon does not bundle or install `claude`. It never reads, stores or overrides your Claude sign-in. You sign in to Claude yourself. Its models appear as Opus, Sonnet and Haiku.
- **ChatGPT plan.** Choose "Sign in with ChatGPT" and finish signing in your browser. Your tokens are kept encrypted on this device. Its models appear as Luna and Sol.
- **Sign out or turn off at any time.** You can sign out of the ChatGPT plan, or turn either provider off, in Settings. Signing out of your account removes the ChatGPT sign-in, the plan settings and the temporary folders the Claude provider uses on this device, along with the rest of your account data.
- **Usage limits.** A usage limit from either plan shows its own message.
- **Personal use only for now.** Wider use needs approval from Anthropic and OpenAI, and that approval is still open.

## Settings and the sidebar

- **One section per list.** Private models, Model providers and MCP servers each read as one section with its list. Lines remain between items and between sections.
- **Support line at the bottom.** "For further help, email support@xfalcon.ai." now sits at the very bottom of Settings.
- **Release notes show only the notes.** The release notes viewer no longer shows a Markdown label or the Copy and Show source buttons above the notes.
- **The "+" on Chats waits for a chat.** It stays hidden until a new chat can start.
- **Resize handle.** The sidebar's resize handle is named "Resize sidebar" and is the last stop in keyboard tab order.
- **Focus after collapse.** If you collapse the sidebar while the resize handle has focus, focus moves to the title bar toggle.

## macOS

- **Folder prompts explain themselves.** When xFalcon asks for access to Documents, Desktop, Downloads or a removable drive, the prompt says why the access is needed.
- **macOS 13 or later.** xFalcon now declares macOS 13 as its minimum version.
- **Narrow windows.** In windows 900 pixels wide or narrower, the sidebar toggle sits clear of the close, minimise and zoom buttons.
- **Dragging and zoom.** You can drag the window by the header, and double-click the header to zoom, on macOS only. Version 0.5.43 enabled these on every platform. This corrects that.
- **Window buttons.** The window buttons are placed more reliably. If they cannot be placed, xFalcon writes the reason to its log.

## Rate limits and tools

- **Rate limits while connecting.** An MCP server that rate limits while xFalcon connects to it is reported as a rate limit, with the wait it asked for. xFalcon does not retry it.
- **A rate limit answered to a cancel.** It is no longer blamed on a later failure.
- **Cut-off replies.** If a reply stops while the assistant is writing a tool call, the chat says so. It no longer shows an output-limit message that does not apply.

## Security and maintenance

- **Narrower link opener.** The app opens only http, https, mailto and tel links. It can no longer reveal a file in its folder.
- **Dependency policy cleaned up.** Two stale advisory ignores were removed. Each remaining ignore names its crate and the date it was last reviewed.
- **Safety notes in Windows code.** Nine `unsafe` blocks in the Windows clipboard and PDF code now have safety comments.
- **Documentation.** The security, operations and configuration documents were updated for these changes.

**Release review note:** The Claude subscription and ChatGPT plan providers are off by default and for personal use only until Anthropic's and OpenAI's approvals for wider use are confirmed. Neither plan provider has a recorded live run. The macOS changes (folder prompts, window buttons, drag and zoom) have no recorded result on a real Mac. The release job compiles and lints the macOS code on macOS, but this repository holds no record of that run or of the window buttons on screen. Windows packages remain unsigned, because the optional Windows signing certificate is not configured. These notes make no SOC 2 certification claim.
