# xFalcon Desktop v0.5.45

Changes since v0.5.44:

## Models

- **Models grouped by source.** The Settings "Default model" list shows models under the headings OpenRouter, Private models, Claude account and ChatGPT plan. A Claude Sonnet is no longer confused with an OpenRouter Sonnet.
- **Claude account in the composer.** The composer says "Using Claude account" when the chat uses a Claude model.
- **Chat model name at once.** Reopening a chat shows its model name at once, instead of "Loading model…". The model list reloads quietly in the background.
- **List refresh.** Changing the default model or a custom model refreshes the model list.

## Claude account reliability

- **No refusal after idle.** A Claude chat no longer refuses to send with "This conversation uses a plan model that is not available right now" after about 30 seconds of idle time.
- **Claude models stay offered.** The Claude models stay offered for up to 10 minutes after the last successful check. They survive a failed check. A slow check finishes in the background instead of being thrown away.
- **Replies without streamed text.** A reply that the Claude program sends without streamed text is shown. It no longer ends as an empty turn.
- **Sign-in retry.** A brief sign-in retry inside Claude no longer ends the turn with a sign-in error.
- **Rate-limit warning.** A rate-limit warning no longer ends the turn when extra usage is available.
- **Clearer failure messages.** A prompt that is too long, a sign-in problem, a plan usage limit and a temporary outage each get their own message. An HTTP 429 from Claude reads as a plan usage limit and is not retried.
- **One attempt when Claude fails to start.** If the `claude` command exits with an error before it prints anything, xFalcon fails once and logs the exit status. It no longer retries three times.
- **Minimum Claude Code version.** The minimum Claude Code version is now 2.1.295. Settings says "update Claude Code" below that version.
- **xFalcon tool entry.** Claude Code always loads the xFalcon tool entry.

**Release review note:** The Claude and ChatGPT plan providers stay off by default and for personal use only until Anthropic's and OpenAI's approvals for wider use are confirmed. The Claude changes were checked against the Claude Code release notes and the open-source t3code client. They have not been run against a recorded live Claude turn. macOS behaviour has no recorded result on a real Mac. Windows packages remain unsigned. The Windows signing certificate is not configured, and no Windows signing service is configured. These notes make no SOC 2 certification claim.
