# xFalcon Desktop v0.5.46

Changes since v0.5.45:

## Private models

- **Any http or https address.** A private model no longer needs an https address with a public name. In Settings > Models you can add a model served on this computer or on your network, for example `http://localhost:8000/v1` or `http://127.0.0.1:8000/v1`. An IPv4 address, a bracketed IPv6 address and any port all work. A scheme is still required: `http://` or `https://`.
- **The key is not encrypted over http.** An `http://` address sends the API key unencrypted. The form says so.
- **Saving needs the service change.** Saving needs the xFalcon service (DA) change that was deployed to staging on 2026-10-22. An older service still refuses these addresses.

## Claude account

- **Reasoning effort.** Settings > Claude has a "Reasoning effort" select with five levels: Low, Medium, High (recommended), Extra high (xhigh) and Max. The default is High. Claude models ran at Medium before this release, because no level was passed.
- **Every Claude run uses the level.** Each Claude run starts with the level chosen in Settings.
- **A chat keeps its level.** Changing the setting affects new chats. A chat keeps the level it started with. A chat that was started before this release has no stored level yet. Its next Claude turn takes the setting in force at that time, and it keeps that level after that.
- **Higher levels cost more.** Higher levels think longer and use more of your Claude plan.

## ChatGPT plan

- **Cache routing headers.** ChatGPT plan requests now carry the conversation id in three routing headers: `session-id`, `thread-id` and `x-client-request-id`. They are sent so that OpenAI can reuse its prompt cache. The effect is not measured. Measuring it needs a ChatGPT plan that OpenAI has approved for this app.

**Release review note:** The Claude and ChatGPT plan providers stay off by default and for personal use only until Anthropic's and OpenAI's approvals for wider use are confirmed. The five Claude reasoning levels were run live on Windows with `claude` 2.1.296: one turn at each of Low, Medium, High, Extra high and Max, a plain turn that ran at High, and a turn with a declared tool. The effect of the ChatGPT headers is not measured, and no live ChatGPT turn has been run. macOS was only type-checked and linted for `aarch64-apple-darwin`. There is no recorded result on a real Mac. Windows packages remain unsigned. The Windows signing certificate is not configured, and no Windows signing service is configured. These notes make no SOC 2 certification claim.
