# xFalcon Desktop v0.5.47

Changes since v0.5.46:

## Office files in projects

- **PDF preview for Word, PowerPoint and Excel.** A `.doc`, `.docx`, `.ppt`, `.pptx`, `.xls` or `.xlsx` file in a project now opens as a PDF preview in the file viewer. Preview is the default view. Word and PowerPoint files also keep a Text view, one click away. Chat attachments are unchanged: they still go to the model as extracted text.
- **Made by a program you already have.** xFalcon does not bundle or install anything for this. It asks Microsoft Office on your computer to write the PDF, hidden, with the file opened read-only and macros off. If Microsoft Office is not installed it tries LibreOffice, and on Windows then WPS Office. WPS Office is given only `.docx`, `.pptx` and `.xlsx` files that carry no macro project, because it has no switch to turn macros off. If one of these programs is installed but cannot open the file, for example a password-protected file, you get that answer; xFalcon does not pass the file to another program.
- **Opening a file starts that program in the background.** The preview is made when the file opens. Cancel stops it. If no supported program is installed, the viewer says which ones work, and Save a copy still works.
- **Save PDF and Save a copy.** Both open the system save dialog; the original file is never changed.
- **Fit page.** The preview opens with the whole page scaled to fit the window, with no scroll bars. Fit width and zoom are still there.
- **No repeat work.** Switching between Preview and Text does not make the PDF again. A finished PDF is kept in memory (never on disk, up to 8 files) and reused while the file is unchanged; any change to the file makes a new one.
- **File types in the project tree have their own colours.** Word, PowerPoint, Excel and CSV are now easy to tell apart.

## Fixes

- **Old PowerPoint text.** Text in `.ppt` files that uses curly quotes, dashes or the euro sign was blanked out in chat attachments and project reads. It now reads correctly.
- **Damaged `.ppt` files.** A `.ppt` file whose slides all point at the same record is refused as invalid instead of repeating that slide's text.
- **Cleanup.** The temporary copy of a file made for a preview is removed when the preview ends, and any left behind by a crash is removed at the next preview.

**Release review note:** The preview was run on one Windows PC with Microsoft Office installed: a `.docx`, a `.pptx` and an `.xlsx` each produced a valid PDF and left no Office process behind. Your organisation's Office settings can block the older `.doc` and `.ppt` formats; that is reported as "could not open". The macOS preview scripts, and the LibreOffice and WPS Office fallbacks on every platform, have not been run on a machine that has those programs. macOS was only type-checked and linted for `aarch64-apple-darwin`, and there is no recorded result on a real Mac. The first preview on a Mac may ask for permission to control Microsoft Office. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
