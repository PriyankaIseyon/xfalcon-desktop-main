# xFalcon Desktop v0.5.48

Changes since v0.5.47:

## Reports

- **Workbooks and decks open as a PDF preview.** In the Reports library, a workbook (`.xlsx`) or deck (`.pptx`) report now shows its pages as a PDF, as Word, PowerPoint and Excel files already do in a project. Before, it showed only a download card. Dashboards are unchanged.
- **Same programs, same safeguards.** The preview is made by a program already on your computer: Microsoft Office first, then LibreOffice, and on Windows then WPS Office, with the file opened read-only and macros off. xFalcon fetches the file from your workspace, converts it in memory, and never writes the PDF to disk.
- **It starts when the report opens.** A Cancel button stops it. If no preview can be made, the viewer says why, and Download and Try again are still there. Download still saves the original file.
- **No repeat work.** A finished PDF is reused while your workspace reports the same version of the report, so reopening an unchanged report fetches and converts nothing. Refreshing the report makes a new preview.

**Release review note:** The report preview has not been opened against a real workbook or deck report in the packaged app; it was checked with tests and compiled and started on Windows. It shares the conversion code of the project preview, which ran on one Windows PC with Microsoft Office installed. The macOS preview scripts, and the LibreOffice and WPS Office fallbacks on every platform, have not been run on a machine that has those programs. macOS was only type-checked and linted for `aarch64-apple-darwin`, and there is no recorded result on a real Mac. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
