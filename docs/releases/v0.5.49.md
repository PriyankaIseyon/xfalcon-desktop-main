# xFalcon Desktop v0.5.49

Changes since v0.5.48:

## Office preview

- **PowerPoint decks preview on macOS.** On a Mac, a deck always showed "The preview could not be created." PowerPoint for Mac ignores a plain-text output path and saves nothing without reporting an error, so no PDF was made. The preview now gives PowerPoint the output as a file reference, which it honours. Word and Excel previews on macOS are unchanged.
- **Failed previews leave a trace.** Every Office preview now writes its outcome to the app log: finished (time and PDF size), cancelled, or failed with the kind of failure. When the program ends without a PDF, the log names the program, its exit code and why the output was refused. On macOS the AppleScript error text is kept as one short, redacted line. These lines are redacted like the rest of the log and carry no document content. Windows and LibreOffice error output is still discarded.

**Release review note:** The macOS fix and its log lines were made on a Mac without a Rust toolchain; this release's review compiled and linted them, and tested them on Windows. The PowerPoint script change is recorded by its author as checked by hand with Microsoft Office 16.114 for Mac; no automated macOS run exists, and the macOS packages were not installed or launched during this review. Cancelling a macOS preview still leaves the Office program open. The LibreOffice and WPS Office fallbacks have not been run on a machine that has those programs. A workbook or deck report has not been opened in the packaged app against a real tenant. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
