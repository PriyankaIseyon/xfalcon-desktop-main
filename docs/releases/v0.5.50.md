# xFalcon Desktop v0.5.50

Changes since v0.5.49:

## MCP servers

- **Production MCP servers can be added again.** Adding a server hosted on `*.mcp.iseyon.com` ended in "OAuth configuration is unavailable or unsupported" as soon as it was saved, on macOS and Windows alike. The app sent no `User-Agent` header, and the firewall in front of those servers refuses any request without one. Sign-in read that refusal as a server with no sign-in details. The app now identifies itself as `xFalcon-Desktop/<version>` on every request to an MCP server and its sign-in server. Staging servers were never affected.

## App icon

- **A larger falcon.** The mark now spans 78% of the icon instead of 72%, on macOS and Windows.

**Release review note:** The `User-Agent` fix was checked against the live `xfalcon-tko-sf-osi-demo.mcp.iseyon.com` server from a test build: discovery failed before the change and resolved both the server and its sign-in server after it. A full sign-in in the packaged app has not been run. On macOS 26 and later the icon still shows inside a white tile in Finder lists; the native icon that fixes this is in the source but left out of this build, because the release runner could not compile it. Windows packages remain unsigned. These notes make no SOC 2 certification claim.
