## Validation limits

A final read-only release review found no blocking or important feature defects.
The dependency audits were also rerun on this change and on a clean archive of
v0.5.50 (`5f3806c`). Both produced the same failures: nine distinct RustSec
advisories, and 17 npm findings (3 high, 14 moderate). Production npm dependencies
had no audit findings. No dependency or advisory-policy change is included in
this feature; the security gate remains unresolved. The Rust findings include
TLS certificate validation and file-parser issues and need separate remediation
before the dependency gate can pass.

The current RustSec findings are `RUSTSEC-2026-0370`, `RUSTSEC-2026-0371`,
`RUSTSEC-2026-0372`, `RUSTSEC-2026-0382`, `RUSTSEC-2026-0383`,
`RUSTSEC-2026-0386`, `RUSTSEC-2026-0387`, `RUSTSEC-2026-0429` and
`RUSTSEC-2026-0436`. This is an audit result, not an accepted security exception.

Native macOS compilation and execution were not available on this host. The
changed React and Rust scope enforcement is shared by Windows and macOS, but
Windows checks do not establish native macOS behavior. Live company-server OAuth
and model-provider end-to-end runs were not performed. No app was pushed,
released or installed by this change.
