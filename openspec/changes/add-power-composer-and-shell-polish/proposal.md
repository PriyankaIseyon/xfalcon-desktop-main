# Power Composer & Minimalist Shell Polish

## Why

The current composer is a standard multiline text box, and the desktop frame uses basic flat background colors. To stand alongside world-class AI desktop applications like Claude Desktop, ChatGPT, and Antigravity, xFalcon needs a **power-user composer** with fluid keyboard shortcuts and a **minimalist, distraction-free native desktop shell**.

A minimalist, high-craft interface keeps the user focused on data and analysis while providing instant keyboard access to files, MCP tools, prompt templates, and active token budgets.

## What Changes

- **`@` Resource Mentions in Composer:** Typing `@` opens an instant popup allowing users to reference local project files, MCP tools, database tables, or saved reports directly into the prompt as rich context pills.
- **`/` Slash Command Menu:** Typing `/` brings up quick shortcuts for skills, prompt playbooks, clearing context, switching models, and changing reasoning depth.
- **Live Context & Token Meter:** A subtle, minimalist token gauge next to the composer displaying current prompt token count, context window ceiling, and prompt cache hit status.
- **Minimalist Shell & Native Window Vibrancy:**
  - Enables Windows 11 Mica / macOS Acrylic native vibrancy for subtle, premium backdrop translucency.
  - Eliminates visual clutter with refined typographic hierarchy, subtle borders (`border-subtle`), and smooth 60/120fps micro-animations.
  - Adds keyboard shortcut overlay (`Cmd+/` or `Ctrl+/`) and quick Zen/Focus mode to hide sidebars during deep reading.

## Capabilities Affected

- `power-composer-and-shell-polish` (new capability)
